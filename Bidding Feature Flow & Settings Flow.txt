1. Feature Overview: Bidding System

The bidding system allows sellers to list items for auction, and buyers to place bids within a
defined time frame. Once the auction ends, the highest bidder wins. Admins oversee all
activities.



2. User Roles & Screen List

A. Buyer Screens

   1. Browse Auctions Screen

           o   Filter by categories, price, time left, location

           o   Sort by newest, ending soon, highest/lowest bids

   2. Auction Detail Page

           o   Item images, description

           o   Current bid

           o   Time remaining (Realtime countdown)

           o   Seller profile

           o   Bid history

           o   "Place Bid" button

           o   Buy Now option (if enabled)

   3. Place Bid Screen (Modal or Inline)

           o   Enter bid amount

           o   Auto-bid toggle (optional)

           o   Confirm bid button

           o   Show minimum next bid requirement

   4. My Bids / Watchlist

           o   Track active and past bids

           o   Bid status (winning/losing/won/lost)

           o   Notifications for outbid, auction ending, won, etc.
   5. Checkout / Payment

           o   Triggered if buyer wins

           o   Payment options (linked wallet, PayPal, card, Lengo Lingo (M-Pesa)

           o   Shipping details

   6. Bid Success / Summary

           o   Confirmation screen with details of winning bid

           o   Option to message seller or view order status



B. Seller Screens

   1. Create Auction

           o   Upload product images

           o   Title, description, category

           o   Starting price

           o   Reserve price (optional)

           o   Buy Now price (optional)

           o   Auction duration (e.g., 1 day – 14 days)

           o   Shipping info

   2. Manage My Listings

           o   View all active, ended, scheduled auctions

           o   Edit, pause, or delete auction (if no bids yet)

           o   See current highest bid and time left

   3. Auction Detail (Seller View)

           o   Bids received

           o   Bidder profiles

           o   Finalize deal if auction ends

           o   Message winning bidder
   4. Post-Auction Management

          o   Mark item as sold

          o   Mark item as shipped

          o   View payment confirmation

          o   Rate buyer



3. Optional Features to Consider

   •   Auto-Bid Feature: User sets max bid, system auto-bids until limit is reached

   •   Verified Sellers: Badge for trusted sellers

   •   Auction Extensions: Extends time if bids are placed near end (anti-sniping)

   •   Bid History Transparency: Optionally anonymized for privacy
